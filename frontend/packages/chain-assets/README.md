# 链图标

下载、查询和旧版链选择器通过 `getChainLogo` 使用同一份本地资源。Vite 将图标随应用发布，不请求外部图标服务。

支持 Ankr Advanced API 的 17 条主网，以及 TRON、Solana 和现有 Bitcoin 查询图标；未登记的链仍使用各组件原有占位图标。

`sources.json` 保存每个文件的原始来源和 SHA-256。Trust Wallet 文件沿用其 MIT 许可，品牌标识归各自权利人所有；其他文件来自链官网或 ethereum-lists 的链 ID 图标登记。

Story 使用登记为 Story、链 ID 1514 的历史标识，与现有 `story_mainnet` 名称一致。Fantom 使用链 ID 250 的 Fantom 标识。
