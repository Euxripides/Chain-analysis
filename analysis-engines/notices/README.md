# Contract analysis dependency notices

The runtime retains dependency license files under /engine/node_modules and system notices under /usr/share/doc. inventory.json records exact npm integrity and compiler identities. Solidity compiler core uses GPL-3.0; solc-js wrapper licensing is recorded separately. Compiler source links point to each reported commit. Heimdall and Anvil binaries are unmodified upstream releases. No Slither, Gigahorse, Halmos or Mythril executable is shipped.
