# Contract analysis dependency notices

The runtime retains dependency license files under /engine/node_modules and system notices under /usr/share/doc. inventory.json records npm integrity and compiler identities. Solidity compiler core uses GPL-3.0; solc-js wrapper licensing is recorded separately. Compiler source links point to each reported commit. Heimdall and Anvil binaries are unmodified upstream releases. The EVM coverage runtime also includes pinned Slither, crytic-compile, Gigahorse and Vyper dependencies. coverage-dependencies.json records Git commits and copied upstream license hashes; requirements.coverage.lock pins Python packages. OpenZeppelin is used for public local-build benchmarks. Native TRON/Solana entry points remain disabled in this release.
