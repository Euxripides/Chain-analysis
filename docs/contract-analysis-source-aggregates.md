# 源码内存结构体分析

本单元继续通用合约分析目标中的声明身份、定义使用、分支合流、内存、整数、跨过程、金额公式、证据和资源调度能力。规则为 `funds-semantics-19`。当前处于候选验证阶段，尚未生产部署。

## 值与引用

结构体及字段使用编译器声明 ID。支持含标量字段和最多四层嵌套结构体的内存构造、位置参数、命名参数、局部绑定、别名、引用重绑定、内部参数、只读内部返回和标量、枚举、结构体混合返回。

对象与局部引用分开保存。字段读取绑定当时的对象版本；后续写入不改变已捕获的标量值。引用重绑定保留旧别名指向的对象。元组赋值先捕获全部右侧值，再修改目标引用。正常分支合流保留条件，终止分支不影响正常后继。

枚举值来自编译器枚举定义中的成员顺序。旧编译器未提供成员引用 ID 时，使用其枚举类型声明引用，在该声明内定位成员。同名成员不能跨枚举建立值身份。

## 未解析的效果

尚未建模的字段写入使所有可能别名的后续读取失效。未知内部调用、汇编、循环和 try/catch 合流分别保存原因。普通兄弟表达式之间存在读写干扰时，不选择一种求值顺序；相关表达式及后续引用保留具体缺项。后续完整重绑定可以建立新的已知对象。

新对象要求已知的编译器内存分配状态。未知汇编修改分配器后，不将后续构造当成互不重叠的新对象。构造参数的副作用、其他字段的失败条件及返回路径的求值依赖保留在结果中。

数组、bytes、string 字段、未初始化引用和未绑定入口内存继续保留缺项。已有字节内存、动态 ABI 和存储引用模型分别处理各自范围。

## 结果读取

对象版本、字段读取和只读返回位于 `expressions`；局部引用绑定位于 `dataflow`。对象版本保存字段声明、字段表达式、父版本、源码调用范围和证据。失败字段读取仍引用造成失效的版本及写入证据，不恢复旧值。

方法包含 `source_aggregate_version_expression_ids`、`source_aggregate_field_expression_ids` 和 `source_aggregate_reference_binding_ids`。方法详情中的 `aggregate_model_references` 给出现有表达式、数据流分区的按方法分页查询及准确记录数。查询返回该方法全部分区记录，其中 `aggregate_records` 表示结构体模型记录数。

继续使用现有九个 MCP 工具，不增加数据库迁移、路由或权限。完整权限、协议经济和所有执行路径证明仍为 false。

## 资源

每方法最多 256 个对象版本，每任务最多 2048 个版本；对象版本、字段和引用绑定合计最多 8192 个记录。每对象最多 32 个字段，嵌套深度 4，条件引用树最多 64 个节点、16 层，求值缺项索引每方法最多 4096 项，返回依赖最多 128 项。达到上限保存前沿，不让共享哨兵成为值身份。原表达式、任务时间、取消和检查点限制继续适用。

使用编译器枚举或内存结构体类型的内部返回摘要，共享附加表达式预算。默认上限为总源码表达式预算的八分之一，即6250；尝试失败的展开也计入消耗。达到预算后，该摘要保存 `INTERNAL_RETURN_ADDITIONAL_EXPRESSION_BUDGET` 前沿和具体调用位置，相关公式与条件保持未解析，继续分析方法剩余语句和普通标量摘要。总源码表达式上限仍为50000，单方法仍为8000。引擎预算记录包含实际附加消耗与上限。

## 大结果工件

原 JSON 超过 128 MiB 展开上限时，先将 1 MiB 至 32 MiB 的普通文本工件以 gzip 保存，保留原 kind 和工件身份。`text_artifact_compression` 索引提供 `text-artifact-compression-v1` 清单，记录原文件名、媒体类型、原始及压缩哈希和字节数。按工件 SHA 校验下载后解压即可读取原文。后端需要解析的证明、状态语义、源码 PC 映射和结论依赖工件维持各自格式。

若结果仍超限，较大的 `dataflow.successful_return_paths` 明细保存在 `dataflow_return_paths` gzip 工件中。原行的 `successful_return_paths_reference` 提供 `artifact_id`、`record_path`、原数组 `sha256` 和 `record_count`；通过现有工件工具读取、校验并解压后，可恢复完整路径、条件和执行步骤。行中的派生状态、具体缺项、表达式和证据不变。路径明细的工件表示不改变这些状态。

普通结果保持原 JSON 协议。64 MiB 传输、128 MiB 展开及 32 MiB 工件上限保持原值，处理后仍超限的结果继续失败。
