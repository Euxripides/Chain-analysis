# 合约交易前状态与升级历史

继续已批准的缺口开发。生产保持 funds-semantics-8，前阶段 funds-semantics-9 候选已提交并通过隔离验收；其源码、镜像、二进制和验收包均已冻结。本阶段使用 contract-transaction-history-20261016 独立工作树。

先修复实际交易前状态采集。普通 prestateTracer 请求启用 includeEmpty，diffMode 请求不携带该选项。[Geth 的实现](https://raw.githubusercontent.com/ethereum/go-ethereum/v1.16.9/eth/tracers/native/prestate.go)会在默认请求中删除原本为空的账户；保留空账户能够取得实际交易位置的状态。固定镜像 Geth 的实测已覆盖新建空账户、同区块先充值后创建及同区块无关交易后创建，复现上一区块余额为 0 而创建交易前余额为 123。跨客户端重放使用固定 Osaka 规则；不同规则下的失败样本单独保留。

仅在节点返回参数错误时允许一次去除该选项的兼容请求，继续使用同一任务预算；限流、超时、预算不足和其他错误不触发额外追踪。逐一检查调用树中的创建目标是否出现在见证中，回滚帧也需检查。缺失或无效账户继续保留缺口，不补写合成零账户，不以父区块值代替交易前值。

重放继续核对实际执行的区块字段。状态核对改为比较双方完整的交易差异，包含额外账户变化、额外存储写入和清零；区块结束的系统调用不再混入用户交易后状态。原始差异、重放差异和规范化比较一起保存并校验哈希，缺失的交易前值继续形成缺口。实际 Geth 样本覆盖创建、同区块充值、区块环境读取及汇编存储清零；删除原始差异中的真实写入或账户变化时，不得生成可信调用点证据。

随后关联初始化与升级的物理存储写入、代码版本和委托调用，并推进命名空间状态布局。签名、多签、外部副作用和协议价格、费用、取整、债务、清算仍沿原计划继续。

公共查询预算继承累计 1558 HTTP、311600 credits、估算 USD 0.0311595741；上限仍为 2000 HTTP、1000000 credits、估算 USD 10。本地 Geth、Anvil 交易只运行于隔离测试链。完整权限与完整经济模型保持未完成，发布前继续执行真实服务、数据库、文件、审计和页面验收。
