# 项目代码规范

## 前端提示交互

1. 前端不允许把提示性内容直接嵌入页面布局。
2. 警告、风险说明、口径说明、操作结果、成功信息、错误信息和需要用户确认的内容，必须通过弹窗呈现。
3. 弹窗必须具有明确标题、正文和关闭操作；需要用户决策时提供清晰的主操作与取消操作。
4. 弹窗关闭后不得继续占据页面空间，不得导致数据卡片、表格或主要操作区域产生永久位移。
5. 页面正文只保留业务数据、字段标签、导航和操作控件。不得使用横幅、内嵌提示卡、常驻警告条或说明段落代替弹窗。
6. 新增或修改前端功能时，必须在桌面端和移动端验证弹窗的遮罩、层级、关闭、键盘焦点和内容滚动行为。

字段名称、按钮文字、表头和数据来源标签属于界面本身，不属于提示信息；但对其含义的额外解释必须放入弹窗。

## 验证要求

- 前端修改不能只以构建成功作为通过标准，必须验证真实页面渲染和交互。
- 至少检查桌面端和一个移动端宽度，不得出现遮挡、溢出、布局跳动或不可关闭状态。
- 涉及后端数据的界面必须核对接口实际响应，不得用占位值冒充官方或真实数据。
