## 2. 本轮 Bug 记录与修复

| ID | 严重度 | 复现结果 | 修复与回归 |
|---|---|---|---|
| BUG-01 | P0 | `0xZZZZZZZZ` 被误分类为原生转账/空调用 | 新增 `invalid_input` 分类、结构化展示及回归测试 |
| BUG-02 | P0 | ABI Parser/Decoder 缺少 JSON、字段数、嵌套深度、输出节点和静态复杂度上限 | 增加 4 MiB ABI、10K entries、1024 tuple fields、深度 32、10 万节点/数组元素、1 MiB calldata 上限及 panic boundary |
| BUG-03 | P0 | Anonymous Event 总把 `topics[0]` 当 topic0 | ABI 保存 `anonymous`；匿名事件从 indexed topic 0 开始解码；多候选保持 Unknown |
| BUG-04 | P0 | PostgreSQL 18 回填状态更新报 `SQLSTATE 42P08`，任务永久 PENDING | 状态参数显式转换 `varchar`；原任务继续执行成功 |
| BUG-05 | P0 | Ankr 真实响应的 32-byte method id、`valueDecoded`、`function ... returns()` 未兼容，导致 selector 为空、签名错误、参数 null | 兼容真实响应形态，规范化 selector/signature/value；真实交易 force refresh 与 cache hit 均通过 |
| BUG-06 | P0 | 同为 Ankr 来源时旧错误元数据不会被修复 | 相同来源但 selector/signature/verified/confidence 变化时允许修复并回写 |
| BUG-07 | P0 | Backfill 总数使用非 FINAL 物理行，完成时 `scanned < total` | Count 与 Scan 统一使用 FINAL；后续任务 `8,799,448 / 8,799,448` |
| BUG-08 | P0 | Unknown selector 每次 Backfill 都重复写，第二遍重写 90,430 行 | 比较稳定 Unknown 的全部字段；第三遍 879 万行 `rewritten_rows=0` |
| BUG-09 | P0 | 本地签名候选 API 显示 `verified=true`，与“非合约验证”语义冲突 | 候选统一走合约级 Verified 规则，实测 transfer candidate 为 false |
| BUG-10 | P1 | 移动端 Data Explorer 产生页面级横向溢出 | 操作区移动端换行；Playwright 移动端回归通过 |
| BUG-11 | P0 | Decoded Input 对大型数组直接 `JSON.stringify`，可能冻结浏览器 | 增加深度/节点受限预览、默认折叠及“加载更多”（最高 2000 节点） |
| BUG-12 | P0 | Manual Override 审计缺 actor/before/after/chain/contract/selector | 审计详情补齐；真实写入后查询确认字段完整 |
