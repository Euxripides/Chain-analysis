# V1.4 Token Metadata Enrichment 验收记录

验收日期：2026-09-02
环境：Ubuntu `192.168.31.152`，真实 PostgreSQL / ClickHouse / MinIO / Ankr RPC

## 已修复缺陷

1. API 与 worker 并发启动迁移时，可能同时写入 `schema_migrations`，导致 API 启动失败。迁移器现使用 PostgreSQL advisory lock 串行执行。
2. 历史 ClickHouse 回填会长时间占用主循环，RPC 解析队列无法运行。历史扫描和 4 个受控 RPC worker 现并行运行，手动解析具有更高优先级。
3. 已登记的迁移文件被追加字段后不会重新执行。新增 Raw 回填统计列已移至独立的 `0008` 迁移。
4. 旧 Token 筛选按符号匹配，会把同名或仿冒 Token 混在一起。现在保存并传递合约地址，后端按合约精确过滤。
5. 历史 MinIO 中存在截断的 gzip 分片。回填会记录损坏清单/分片数并继续使用 ClickHouse 与 RPC 降级补全，不删除原始证据。
